# IntoTheVoid 私服 · 简明上手

> 把官方「驱入虚空」跑成**完全离线本地私服**：免改 hosts、免装证书、**游戏本体零修改**。
> 本文件是速查版；完整说明（工作原理、服务端实现细节、FAQ）见根目录 **README.md**。

---

## 一、包内容

```
IntoTheVoidPrivateServer/
├── README.md                 # 完整说明（推荐先读）
├── Server/                   # 服务端【发布版，双击即用】
│   ├── IntoTheVoidServer.exe     # 主程序
│   ├── Data/responses/           # 官方抓包回放数据（73 响应 + 5 推送，必备）
│   ├── Data/tables/              # 掉落/结算配置表（12 张，必备）
│   ├── Data/gamestate.json       # 初始状态（可编辑）
│   ├── wwwroot/admin/            # GM 管理面板
│   └── cert.pfx / rsa_*.txt      # 自签证书与 RSA 密钥
├── Server-Source/            # 服务端【源码版，可二次开发】
├── Client-Plugin/            # 客户端插件【免改 hosts 的核心】
│   ├── BepInEx/                  # core + plugins(UseCustomServer) + config
│   ├── dotnet/                   # IL2CPP 所需 .NET 运行时
│   ├── winhttp.dll               # BepInEx 注入器
│   └── doorstop_config.ini / .doorstop_version
├── Launcher/                 # 登录器【建号 + 启服 + 存档管理】
│   └── publish/驱入虚空登录器.exe
└── docs/
    ├── 使用说明.md               # 本文件
    ├── 一键安装.bat              # 合并插件 + 启动服务端（可选）
    └── update_hosts.bat          # hosts 兜底脚本（可选，正常用不到）
```

**不含游戏本体**，请自备官方客户端。

## 二、前提：运行时

| 组件 | 需要的运行时 |
|---|---|
| `Server/IntoTheVoidServer.exe` | **ASP.NET Core Runtime 10** |
| `Launcher/publish/驱入虚空登录器.exe` | **.NET Desktop Runtime 10 (x64)** |

省事做法：直接装 **[.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)**（一次装齐）。

## 三、四步上手

### 步骤 1 · 部署客户端插件

把 `Client-Plugin/` 里的所有文件**合并到游戏根目录**（与 `IntoTheVoid.exe` 同级）：

```
游戏根目录/
├── IntoTheVoid.exe     (官方原有，不动)
├── IntoTheVoid_Data/   (官方原有，不动)
├── BepInEx/            ← 新增
├── dotnet/             ← 新增
├── winhttp.dll         ← 新增
├── doorstop_config.ini ← 新增
└── .doorstop_version   ← 新增
```

> BepInEx 首次启动会自动生成 `interop/` 与 `unity-libs/`（会等几分钟，只此一次）。

### 步骤 2 · 建号（**必须**）

服务端不含建号接口，没账号会提示「账号不存在」。

双击 `Launcher/publish/驱入虚空登录器.exe`：

1. 顶部「服务端目录」点 **浏览...**，选到本包的 **`Server`** 目录（含 `IntoTheVoidServer.exe` 那层）
2. 点 **新建账号** → 账号填 **3–11 位纯数字**，密码填 **6–32 位**可见 ASCII
3. 初始存档可选「沿用原存档」（按官方快照初始化）或「全新空档」

### 步骤 3 · 启动服务端

登录器里点 **启动服务端**，或直接双击 `Server/IntoTheVoidServer.exe`。

正常启动标志：

```
Loaded 73 captured responses and 5 pushes
Now listening on: ... 0.0.0.0:80 / 443 / 8183 / 30531
```

> ⚠️ 80 / 443 必须空闲 —— 开着 **Watt Toolkit（Steam++）** 之类的加速器请先退出。
> `Loaded 0 captured responses` = `Data/responses/` 缺失。

### 步骤 4 · 进游戏

双击 `IntoTheVoid.exe`（或登录器里点 **▶ 启动游戏（自动拉起服务端）**）。

登录界面切到**官方账号登录** → 输入步骤 2 的账号密码 → 自动进主城 → 可进关卡。

## 四、验证

- GM 面板：<http://127.0.0.1:8183/admin/>（发货币 / 查在线玩家）
- HTTPS 自检：`curl -k https://localhost/ping` → `{"code":0}`
- 日志：`Server/logs/server_YYYYMMDD.log`

> 控制台会持续刷**心跳日志**，属正常现象，不是报错。

## 五、可选脚本

- **`一键安装.bat`** — 自动探测游戏根目录 → 合并 `Client-Plugin/` → 启动服务端
- **`update_hosts.bat`** — 历史兜底脚本，正常用不到（本方案免改 hosts）

## 六、常见问题

| 问题 | 处理 |
|---|---|
| 提示缺少 .NET | 装 .NET 10 SDK 或对应运行时（见第二节） |
| 登录提示「账号不存在」 | 必须先建号，见步骤 2 |
| 弹「系统维护中」 | 确认 `BepInEx/plugins/UseCustomServer.dll` 存在；查 `BepInEx/LogOutput.log` |
| 登录报网络错误 | 确认服务端 443 已监听（`curl -k https://localhost/ping`） |
| 服务端闪退 / 端口占用 | `taskkill /IM IntoTheVoidServer.exe /F` 后重启；确认 80/443/30531 空闲 |
| 首次进游戏卡很久 | BepInEx 正在生成 `interop/`，属正常 |
| 换盘符后连不上 | 设环境变量 `UCS_GAME_ROOT` 指向游戏根目录 |
| 想联机 | 插件把服务器地址写死为 `127.0.0.1`，**仅支持单机** |
