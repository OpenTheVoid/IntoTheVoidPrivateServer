# IntoTheVoid 私服 - 使用说明

> 本包用于把官方「驱入虚空」跑成**完全离线私服**。游戏本体零修改，所有改动都在 BepInEx 插件 + 本地服务端里。
> **免改 hosts、免装证书** —— 直接拷贝、启动、进游戏三步即可。

---

## 一、包内容

```
IntoTheVoidPrivateServer/
├── README.md                 # 总说明 + 快速开始（推荐先读这个）
├── Server/                   # 服务端【发布版，开箱即用】
│   ├── IntoTheVoidServer.exe     # 服务端主程序
│   ├── wwwroot/admin/            # GM 管理面板
│   ├── Data/responses/           # 官方抓包回放数据（74响应+5推送，必备）
│   ├── Data/gamestate.json       # 货币等初始状态（可编辑）
│   ├── cert.pfx / cert.cer       # HTTPS 自签证书（SAN 覆盖官方域名）
│   └── rsa_private_key.txt       # 登录签名 RSA 私钥
├── Server-Source/            # 服务端【源码版，可二次开发】
│   └── (编译需 .NET 10 SDK，见 README「从源码构建服务端」)
├── Client-Plugin/            # 客户端插件【免改 hosts 的核心】
│   ├── BepInEx/                  # core + plugins(UseCustomServer) + config + patchers
│   ├── dotnet/                   # IL2CPP 自包含 .NET 运行时
│   ├── winhttp.dll               # BepInEx 注入器
│   └── doorstop_config.ini / .doorstop_version
└── docs/
    ├── 一键安装.bat              # 合并插件+启动服务端（可选）
    └── update_hosts.bat          # hosts 兜底脚本（可选，见 FAQ）
```

**不包含游戏本体**，请自备官方客户端。

---

## 二、部署步骤

### 前提
- 一套**干净的官方成品客户端**（`IntoTheVoid.exe` 同级）
- 服务端若无法启动需装 [.NET 10 Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)

### 步骤 1：放置客户端插件
把 `Client-Plugin/` 里的所有文件**合并到游戏根目录**（与 `IntoTheVoid.exe` 同级）：
```
游戏根目录/
├── IntoTheVoid.exe     (官方原有)
├── IntoTheVoid_Data/   (官方原有)
├── BepInEx/            ← 拷贝
├── dotnet/             ← 拷贝
├── winhttp.dll         ← 拷贝
├── doorstop_config.ini ← 拷贝
└── .doorstop_version   ← 拷贝
```
> BepInEx 首次启动会自动生成 `interop/` 与 `unity-libs/`，无需手动放。

### 步骤 2：放置并启动服务端
`Server/` 目录可放在任意位置（推荐放在游戏根目录同级）。双击 `Server/IntoTheVoidServer.exe`。

正常启动标志（首屏日志）：
```
Loaded 74 captured responses and 5 pushes
Now listening on: ... 0.0.0.0:80 / 0.0.0.0:443 / 0.0.0.0:8183 / 0.0.0.0:30531
```
> `Loaded 0 captured responses` = `Server/Data/responses/` 缺失，请重新解压。

### 步骤 3：启动游戏
双击 `IntoTheVoid.exe`。登录任意账号密码（本地不校验真实账号）→ 自动进主城 → 可进入关卡。

## 三、验证

- 浏览器打开 GM 面板：<http://127.0.0.1:8183/admin/>（货币发放见面板说明）
- HTTPS 自检：`curl -k https://localhost/ping` → `{"code":0}`
- 服务端控制台/日志 `Server/logs/server_YYYYMMDD.log` 会打印请求回放命中

## 四、可选脚本

### docs/一键安装.bat
自动：探测游戏根目录 → 合并 `Client-Plugin/` → 重启服务端。适合绿色分发。

### docs/update_hosts.bat
仅在遇到 **TapTap SDK 登录域**相关异常时使用（管理员运行）。新版登录链不依赖 hosts。

## 五、常见问题

| 问题 | 处理 |
|---|---|
| 弹「系统维护中」 | 确认 `BepInEx/plugins/UseCustomServer.dll` 存在且与服务端配套；查 `BepInEx/LogOutput.log` |
| 登录报网络错误 | 确认服务端 443 已监听（`curl -k https://localhost/ping`） |
| 进入关卡后没有敌人 | **已知限制**：刷怪链路尚未实现，见根 README |
| 服务端闪退/端口占用 | `taskkill /IM IntoTheVoidServer.exe /F` 后重启；确认 80/443/30531 空闲 |
| 换盘符后连不上 | 设环境变量 `UCS_GAME_ROOT` 指向游戏根目录 |
